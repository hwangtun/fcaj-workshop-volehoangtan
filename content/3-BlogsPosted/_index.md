###  [Blog 1 - Amazon SQS – The Key to Asynchronous Architecture on AWS](3.1-Blog1/)
This blog introduces Amazon Simple Queue Service (Amazon SQS) and its role in building asynchronous architectures on AWS. It focuses on the fundamentals of message queues, the benefits of improved scalability and reliability, and several best practices for integrating Amazon SQS with AWS Lambda to build efficient and resilient serverless applications.

###  [Blog 2 - Event-Driven Architecture – The Foundation of Serverless Systems on AWS](3.2-Blog2/)
This blog introduces Event-Driven Architecture (EDA), a widely adopted architectural pattern for building modern serverless applications on AWS. It explains how event-driven systems work, highlights the benefits of loose coupling, real-time processing, scalability, and cost optimization, and demonstrates how services such as Amazon S3, Amazon EventBridge, AWS Lambda, Amazon SQS, and Amazon SNS can be integrated to build automated and scalable cloud applications.

###  [Blog 3 - AWS CDK – Infrastructure as Code for Modern Cloud Infrastructure](3.3-Blog3/)
This blog introduces AWS Cloud Development Kit (AWS CDK) and its role in implementing Infrastructure as Code (IaC) on AWS. It explains the infrastructure deployment workflow using cdk synth, cdk diff, and cdk deploy, while highlighting the key benefits and best practices of using AWS CDK to build, manage, and automate cloud infrastructure.
