After the Backend Infrastructure is successfully deployed using AWS CDK, the next step is to build and deploy the Frontend application to **AWS Amplify**.

The system's Frontend is developed using **React and Vite**. During the build process, the Frontend needs the Backend's API Gateway URL to communicate with the APIs provided by the system.

After the Backend deployment is completed, the `ApiGatewayUrl` information is stored in the `cdk-outputs.json` file and used to configure the Frontend.

### Step 1: Build the React Source Code

Navigate to the Frontend directory:

```bash
cd frontend/image-optimization-system/image-optimization-frontend
```

Install the required dependencies:

```bash
npm install
```

After the Backend is successfully deployed, the `cdk-outputs.json` file is generated in the project's root directory.

Use the `ApiGatewayUrl` value from this file to create the Frontend environment variable:

```bash
echo "VITE_API_GATEWAY_URL=$(jq -r '.ApiStack.ApiGatewayUrl' ../../../cdk-outputs.json)" > .env
```

Where:

- `VITE_API_GATEWAY_URL`: The API Gateway URL used by the Frontend to communicate with the Backend.
- `cdk-outputs.json`: The file containing output values generated by AWS CDK after the deployment process.
- `.env`: The environment configuration file for the React/Vite application.

After configuring the environment variable, build the Frontend application:

```bash
npm run build
```

If the build process is successful, Vite creates the following directory:

```text
dist/
```

The `dist` directory contains the built static files ready to be deployed to the hosting environment.

> **Note:** The `jq` command used in the example above is suitable for Linux/macOS environments or environments where `jq` is installed. On Windows, the `ApiGatewayUrl` value can be retrieved from `cdk-outputs.json` and the `.env` file can be configured manually according to the current environment.

---

### Step 2: Package the Frontend

After the build process is completed, navigate to the `dist` directory:

```bash
cd dist
```

Compress all files inside the directory:

```bash
zip -r ../frontend-dist.zip .
```

After completion, the following file is created:

```text
frontend-dist.zip
```

The file is generated in the Frontend directory.

Return to the Frontend directory:

```bash
cd ..
```

This ZIP file is used as the source for deploying the application to AWS Amplify.

---

### Step 3: Deploy the Frontend to AWS Amplify

The Frontend can be deployed to AWS Amplify using the AWS CLI.

Execute the following command:

```bash
aws amplify start-deployment \
  --app-id <AMPLIFY_APP_ID> \
  --branch-name main \
  --source-url s3://<BUCKET>/frontend-dist.zip
```

Where:

- `<AMPLIFY_APP_ID>`: The ID of the Amplify App.
- `main`: The branch used for deployment.
- `<BUCKET>`: The S3 Bucket containing the `frontend-dist.zip` file.

After the deployment is created, AWS Amplify uses the provided source to update the Frontend version.

The deployment status can be checked through:

**AWS Management Console → Amplify**

### Frontend Deployment Workflow

The entire process can be summarized as follows:

```text
cdk-outputs.json
       │
       ▼
  ApiGatewayUrl
       │
       ▼
   Frontend .env
       │
       ▼
    npm run build
       │
       ▼
      dist/
       │
       ▼
frontend-dist.zip
       │
       ▼
   AWS Amplify
       │
       ▼
  Frontend Application
```

In a real deployment environment, the Frontend build and deployment steps can be automated through **GitHub Actions**. The CI/CD process will be presented in the next section.
