During my internship at **Amazon Web Services Vietnam Co., Ltd.** from **June 22, 2026** to **August 15, 2026**, I participated in the development of the **Automatic Image Optimization System**. The project was built on the **AWS Cloud** platform and combined **Frontend development (React + TypeScript)**, **Backend development (Spring Boot/J2EE)**, and various **Amazon Web Services**, including **Amazon S3**, **AWS Lambda**, **IAM**, **CloudWatch**, and **Google OAuth**.

Throughout the internship, I gradually explored the technologies involved, implemented the system's core features, integrated the frontend with the backend, performed testing, optimized the application, and completed the final product. The work completed during each week is summarized below:

**Week 1:** [Project onboarding, understanding the working environment, and studying the system architecture](1.1-week1/)

**Week 2:** [Learning AWS, Amazon S3, and AWS Lambda; implementing the image processing workflow](1.2-week2/)

**Week 3:** [Completing the Lambda function, implementing image processing with Pillow, and designing image metadata](1.3-week3/)

**Week 4:** [Developing the frontend with React and implementing the image upload interface](1.4-week4/)

**Week 5:** [Building the Dashboard, Layout, Sidebar, and refining the user interface](1.5-week5/)

**Week 6:** [Integrating the J2EE backend, connecting REST APIs, implementing image upload, and Google OAuth authentication](1.6-week6/)

**Week 7:** [Finalizing system features, resolving integration issues, and performing system testing](1.7-week7/)

**Week 8:** [Optimizing the system, completing documentation, conducting final testing, and preparing the project for delivery](1.8-week8/)
