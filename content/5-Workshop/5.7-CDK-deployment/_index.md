After completing the construction and testing of all system components, the team used **AWS CDK (Cloud Development Kit)** to automate infrastructure deployment as **Infrastructure as Code (IaC)**.

Additionally, the system utilizes **AWS Amplify** to deploy the Frontend and **GitHub Actions** to automate the CI/CD pipeline.
