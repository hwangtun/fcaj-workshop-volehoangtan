During my internship at **Amazon Web Services Vietnam Co., Ltd.** from **June 15, 2026** to **August 15, 2026**, I had the opportunity to gain practical experience and apply the knowledge I acquired at university in a professional working environment.

Throughout the internship, I participated in the development of the **Automatic Image Optimization System**, a cloud-based application designed to optimize images using AWS services. My responsibilities included developing the frontend using **React, TypeScript, and Vite**, integrating it with the **J2EE backend** through RESTful APIs, implementing **Google OAuth authentication**, developing the image upload workflow, and connecting the system with **Amazon S3** and **AWS Lambda** for automated image processing.

Through this project, I significantly improved my technical skills, including:

* Web application development using React and TypeScript.
* User interface and user experience design.
* RESTful API integration.
* Working with AWS services such as Amazon S3, AWS Lambda, IAM, and CloudWatch.
* Implementing authentication using JWT and Google OAuth.
* Version control using Git and collaborative software development practices.
* Debugging, problem-solving, and system optimization.

Besides technical knowledge, I also gained valuable experience in working within a real software development process. I learned how to analyze requirements, collaborate with teammates, research technical documentation independently, and continuously improve my problem-solving abilities.

Regarding my work attitude, I always tried to complete assigned tasks on time, actively accepted feedback from my supervisor, and continuously learned new technologies to improve both my technical knowledge and professional skills.
